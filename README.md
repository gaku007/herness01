# Herness Project

## Overview
This project demonstrates Harness Engineering principles with AI-agent-compatible workflows.

## makeHappy Agent

The `makeHappy` agent generates a React component that delivers happiness!

### Usage

```bash
# Execute the makeHappy agent
makeHappy
```

### Output

The agent creates the following:
- **File**: `src/happy_output.ts` - A React component with a clickable heart button
- **Behavior**: When the heart button (❤️) is clicked, displays "幸せが届きました！" (Happiness delivered!)

### Features

- Displays current timestamp
- Interactive heart button to trigger happiness message
- Simple, clean UI centered on screen
- Built with React and TypeScript

### Example

```typescript
import HappyApp from './happy_output';

// Use the HappyApp component in your render tree
<HappyApp />
```

## Running the Application

### Prerequisites
- Node.js 16+ 
- npm or yarn

### Installation & Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The application will automatically open in your browser at `http://localhost:5173/`

### Features in Action

1. Visit http://localhost:5173/
2. See the current timestamp displayed
3. Click the heart button (❤️)
4. Watch the happiness message appear!

### Build for Production

```bash
# Build optimized bundle
npm run build

# Preview production build
npm run preview
```
